# Barreau Alger — بوابة المحامي الجزائري

نسخة أولية عربية لأدوات PDF المهنية، مع تركيز على الخصوصية.

## الميزات الحالية
- ضغط PDF بإعادة إنشاء الصفحات كصور JPEG داخل ملف جديد.
- استخراج نطاقات صفحات محددة وتقسيم الملف إلى أجزاء.
- دمج ملفات PDF.
- حذف صفحات وتدوير جميع الصفحات.
- تحويل صور JPEG وPNG وWebP إلى PDF.
- قائمة مراجعة عامة قبل الإيداع.
- واجهة متجاوبة واتجاه RTL.

## الخصوصية والقيود
- لا توجد حسابات مستخدمين أو قاعدة بيانات أو نموذج يرسل بيانات إلى التطبيق.
- معالجة الملفات تتم في المتصفح، ولا تُرفع محتوياتها إلى خادم التطبيق.
- مكتبات PDF تُحمّل حاليًا من cdnjs؛ لذلك يلزم الاتصال لتحميلها. ملفات القضايا لا تُرسل إلى cdnjs.
- النسخة الحالية ليست مكتملة الوظائف دون إنترنت. يلزم تضمين المكتبات محليًا واختبار التخزين المؤقت قبل اعتماد التشغيل دون اتصال.
- لا ترفع الملفات إلى مواقع عامة غير موثوقة، واحتفظ بالأصل.

## تحذير مهم بشأن الضغط
أداة الضغط تعيد تحويل كل صفحة إلى صورة؛ وقد تفقد النص القابل للبحث والروابط والنماذج والتوقيعات الرقمية وبعض الجودة. استخدم نسخة تجريبية وتحقق من النتيجة قبل أي إيداع رسمي. وقد لا تصغر بعض الملفات.

## التشغيل المحلي
يمكن فتح index.html في المتصفح مع اتصال بالإنترنت. لاختبار Service Worker، شغّل خادمًا محليًا ثابتًا:

    python -m http.server 8000

ثم افتح http://localhost:8000.

## الملفات
- index.html: الواجهة والأدوات.
- manifest.json: إعدادات التثبيت.
- sw.js: تخزين واجهة التطبيق مؤقتًا.

## الخطوات التالية
1. اختبار ملفات PDF كبيرة ومشفرة ومتعددة الصفحات.
2. تضمين مكتبات PDF محليًا إذا كان العمل دون إنترنت شرطًا إلزاميًا.
3. تحسين ترتيب ملفات الدمج ومعاينة الصفحات.
4. اختبار جودة الضغط وحجم النتائج.
5. إعداد النشر على Vercel بعد التحقق من الإعدادات.
